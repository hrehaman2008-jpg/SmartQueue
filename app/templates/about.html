About This Project

Smart Queue and Digital Token System is a college project built with Python Flask, Flask-SQLAlchemy, and SQLite. It demonstrates a modern digital queue management system for hospitals and clinics, replacing paper tokens with secure, scannable digital tokens.

Tech stack: Python, Flask, Flask-SQLAlchemy, Flask-Login, Flask-WTF, WTForms, SQLite, Bootstrap 5, HTML, CSS, and JavaScript.

Security: Passwords are hashed with Werkzeug's secure password hashing, authentication uses Flask-Login sessions, and all access is enforced server-side by role.

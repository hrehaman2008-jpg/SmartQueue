# SmartQueue Design System

This file defines the design standards for the SmartQueue application.

## Principles
- **Clarity**: Ensure queue status is clear at a glance.
- **Accessibility**: Follow WCAG guidelines.
- **Consistency**: Use Bootstrap primitives as the foundation.

## Foundations
- **Color Palette**:
  - Primary: #0d6efd
  - Secondary: #6c757d
  - Background: #f8f9fa
- **Typography**: Inherited from Bootstrap (default system fonts).
